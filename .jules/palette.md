## 2024-07-24 - Interactive Element Keyboard Accessibility
**Learning:** Found instances where buttons in the UI lacked `focus-visible` styles, leading to poor keyboard navigation feedback (e.g., in `CalendarWritebackSection.tsx`). The app heavily relies on a specific Tailwind class combination (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring/40`) for consistent keyboard focus states.
**Action:** When adding new interactive elements (buttons, links) or reviewing existing ones, always ensure the standard `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring/40` class sequence is applied to maintain consistent keyboard accessibility.
